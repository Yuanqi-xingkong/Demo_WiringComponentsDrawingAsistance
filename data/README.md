# 运行时数据文件

本目录只放占位说明，避免把受控手册、客户图纸、API Key 或生成结果误提交到 GitHub。

服务运行时至少需要把以下文件放到项目根目录，或在代码/启动参数中改成实际路径：

- `中航光电线束物料知识治理结果_final.xlsx`
  - 默认治理知识库。
  - 服务前端也支持上传新的 `.xlsx` 治理文件作为运行时知识库。
- `线缆组件产品接线表格式模板20260420.xls`
  - 输出 Excel 的格式模板。
  - 运行机需要安装 LibreOffice，用于把 `.xls` 模板转换成 `.xlsx` 后再用 `openpyxl` 回填。

PDF 图纸会通过 OCR 服务处理；DOCX 技术要求文件会由后端直接解析正文和表格。

不建议提交到 GitHub 的文件：

- 原始受控选型手册。
- 客户上传图纸。
- `治理输出/` 下的运行记录、OCR JSON、生成的 Excel。
- `.env` 和任何真实 API Key。
