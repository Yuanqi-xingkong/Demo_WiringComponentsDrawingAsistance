# 中航光电线束物料知识治理过程说明

本文说明四个原始选用/选型手册如何治理为 `中航光电线束物料知识治理结果_final.xlsx` 中用于自动选型的五个核心知识表：

- `导线电缆知识`
- `导线标准线径`
- `防护辅材知识`
- `扎带卡扣知识`
- `连接器BOM映射`

治理目标不是简单合并 Excel，而是把不同手册中表头不一致、结构不一致、部分信息来自图片或合并单元格的内容，整理成后续 OCR 图纸理解、候选物料排序和接线表模板回填可以稳定读取的结构化知识库。

## 1. 输入与输出

### 1.1 原始输入文件

| --- | --- |
| `电缆选型手册20251227（JONHON受控).xlsx` | 治理导线/电缆物料知识，以及不同标准下的导线标准线径信息。 |
| `线束扎带选用手册（JONHON受控).xlsx` | 治理扎带、卡扣、固定座、管夹等辅材知识。 |
| `线缆防护辅材选用手册（JONHON受控).xlsx` | 治理波纹管、保护网、铝排编织袖套、套管等线缆防护辅材知识。 |
| `连接器物料选用清单.xlsx` | 治理客户/供应商连接器型号到中航物料号的 BOM 映射关系。 |

## 2. 总体治理原则

治理过程遵循以下原则：

1. 保留来源追溯信息  
   每条知识记录都尽量保留 `来源文件`、`来源工作表`、`来源行号`，方便后续核查原始手册。

2. 统一字段命名  
   不同手册中相同含义的列名被归一到稳定字段。例如 `料号`、`物料号`、`物料编号` 统一到 `物料编号`；`材质` 统一到 `材料`。

3. 去除非选型数据  
   原始手册中的封面、修订记录、说明页、空行、价格类字段、纯展示字段等，不进入核心知识表。

4. 保留选型关键字段  
   自动选型需要的字段优先保留，例如规格、外径、内径、材料、颜色、温度等级、阻燃等级、适配范围、优选等级、备注、分类原因等。

5. 尽量不丢失异构信息  
   对结构复杂的 sheet，不强行套用单一表头解析。特别是 `导线标准线径`，它同时包含普通单元格表格、横向多表结构、图片/OCR 表格内容，因此最终表保留了部分段落标记和 OCR 来源信息。

6. 支持后续自动化使用  
   治理结果最终服务于脚本中的自动匹配逻辑。当前主流程主要读取 `导线电缆知识`、`导线标准线径`、`防护辅材知识`、`扎带卡扣知识`、`连接器BOM映射` 五个 sheet。

## 4. `导线电缆知识` 的治理

### 4.1 来源范围

`导线电缆知识` 来自 `电缆选型手册20251227（JONHON受控).xlsx` 中两个物料目录：

| 来源 sheet | 治理后行数 | 说明 |
| --- | ---: | --- |
| `车载高压电缆优选目录` | 282 | 高压电缆物料优选目录。 |
| `低压电缆优选目录` | 171 | 低压电缆物料优选目录。 |

原始文件中的 `封面`、`变更记录` 不进入该知识表。

### 4.2 原始表头识别

两个来源 sheet 的有效表头位置不同：

- `车载高压电缆优选目录` 的有效字段包括：`序号`、`物料编号`、`屏蔽`、`物料规格`、`符合标准`、`温度等级`、`绝缘护套材料`、`额定电压`、`导体`、`颜色`、`绝缘外径`、`护套外径`、`屏蔽单丝直径`、`备注`。
- `低压电缆优选目录` 的字段结构基本一致，但温度字段在原表中表现为 `温度等级/℃`，治理后统一为 `温度等级`。

### 4.3 目标字段

治理后的 `导线电缆知识` 字段为：

| 字段 | 含义 |
| --- | --- |
| `知识类型` | 固定标识为导线/电缆类知识。 |
| `来源文件`、`来源工作表`、`来源行号` | 记录原始出处。 |
| `选用等级_治理` | 治理后的优选等级，例如一类、二类、三类等。 |
| `等级依据` | 记录等级判断依据，便于复核。 |
| `物料编号` | 中航物料编号。 |
| `屏蔽` | 是否屏蔽或屏蔽类型。 |
| `物料规格` | 线缆规格，例如 `1*3`、`2*4` 等。 |
| `符合标准` | 对应标准，例如 ISO、LV、QC/T 等。 |
| `温度等级` | 线缆温度等级。 |
| `绝缘护套材料` | 绝缘或护套材料。 |
| `额定电压` | 额定电压。 |
| `导体` | 导体类型或结构描述。 |
| `颜色` | 线缆颜色。 |
| `绝缘外径` | 绝缘外径。 |
| `护套外径` | 护套外径。 |
| `屏蔽单丝直径` | 屏蔽单丝直径。 |
| `备注` | 原表备注信息。 |
| `选用条件` | 可用于自动选型的条件描述。 |
| `治理备注` | 治理过程中产生的补充说明。 |

### 4.4 主要治理动作

1. 抽取有效物料行  
   跳过封面、变更记录、空行和非物料说明行，只保留具有物料属性的记录。

2. 统一高压和低压目录字段  
   高压、低压目录虽然表头相近，但列名和位置存在差异。治理后合并到同一套字段，便于后续统一检索。

3. 保留优选等级  
   目标表中保留 `选用等级_治理` 和 `等级依据`。后续导线选择会按一类优先于二类、二类优先于三类的顺序排序。

4. 保留线径相关字段  
   `物料规格`、`绝缘外径`、`护套外径` 是后续导线选型和防护辅材选型的关键字段。例如图纸要求 `3mm²屏蔽线缆` 时，系统会先用标准线径确认截面，再在 `导线电缆知识` 中查找合适规格。

## 5. `导线标准线径` 的治理

### 5.1 来源范围

`导线标准线径` 主要来自 `电缆选型手册20251227（JONHON受控).xlsx` 的 `导线标准线径` sheet。

该 sheet 与普通物料表不同，结构更复杂：

- 同一 sheet 中可能存在多个标准表。
- 部分表格是横向排列的宽表。
- 部分标准线径信息来自嵌入图片或截图。
- 后续又通过 OCR 或 MinerU 表格解析补充了 QC/T1037、ISO19642 等标准表内容。

因此，`导线标准线径` 不是一个完全规整的单表，而是“结构化字段 + OCR 表格段落”的混合治理结果。

### 5.2 目标字段

当前目标表的前几个核心字段为：

| 字段 | 含义 |
| --- | --- |
| `来源文件` | 原始文件或 OCR 补充来源。 |
| `来源工作表` | 来源 sheet，一般为 `导线标准线径`。 |
| `来源行号` | 原表行号或补充内容行号。 |
| `标准` | 标准名称，例如 LV216、QC/T1037、ISO19642 等。 |
| `导体标称截面` | 标称截面积，例如 3mm²。 |
| `绝缘外径` | 对应标准下的绝缘外径范围或数值。 |
| `护套外径` | 对应标准下的护套外径范围或数值。 |

由于该 sheet 追加了 OCR/图片表格内容，后续列可能没有统一表头。自动选型脚本中已经为该 sheet 单独实现了解析器，而不是使用普通的 `load_sheet_rows()` 通用读取逻辑。

### 5.3 主要治理动作

1. 从原始单元格中提取标准线径  
   对原 sheet 中可直接读取的表格，提取标准、导体标称截面、绝缘外径、护套外径等字段。

2. 拆解横向多表结构  
   对一个 sheet 内横向并排的多个标准表，按实际表格块拆解为多条标准线径记录。

3. 追加图片/OCR 表格  
   对嵌入图片、截图或难以用 openpyxl 直接读取的标准表，通过 OCR/表格解析结果补充到该 sheet 中。最终表中会出现类似标准段落标题、来源图片说明等内容。

4. 支持后续线缆规格匹配  
   当图纸 OCR 中出现 `3mm²屏蔽线缆` 这类需求时，后续流程会先在 `导线标准线径` 中定位 `3mm²` 对应的标准外径，再结合 `导线电缆知识` 中的 `物料规格`、`屏蔽`、`护套外径`、`优选等级` 生成候选导线。

### 5.4 为什么不能完全走通用表格解析

普通 sheet 可以把第一行作为表头，然后逐行读取。但 `导线标准线径` 存在以下问题：

- 有些行是标准段落标题，不是数据行。
- 有些行是 OCR 来源说明，不是物料记录。
- 有些表格列是横向展开的，通用表头读取会丢失右侧宽表字段。
- 有些单元格为空，但实际语义需要继承上方或左侧标准名。

因此，当前脚本中对 `导线标准线径` 使用专门解析逻辑，避免丢失标准线径字段。

### 6.4 主要治理动作

1. 按辅材类型设置 `知识类型`  
   波纹管、保护网、铝排编织袖套、套管进入同一张知识表，但通过 `知识类型` 区分。

2. 统一选型关键字段  
   防护辅材自动选择需要综合内径、外径、材料、颜色、阻燃、温度和优选等级，因此这些字段被统一保留。

3. 保留分类原因  
   原表中的 `分类原因` 对解释为什么优先选择某个物料有价值，因此治理后继续保留。

4. 支持按图纸约束筛选  
   例如图纸指定波纹管且要求外径不超过 16mm，系统可以结合导线外径估算线束直径，再在 `防护辅材知识` 中筛选内径满足、外径满足、颜色和材料优先级合适的候选项。

   原表中有些写线束外径，有些写孔径、管径、螺栓，有些写钣金厚度。治理后统一为几个适配字段，方便自动筛选。

3. 保留图片核查信息  
   对依赖图片识别或图片确认的行，治理后保留 `同源行图片数` 和 `图片有效性`，便于追溯该物料图片是否可用。

4. 保留选用备注  
   选用备注中可能包含限制条件或推荐场景，因此不直接丢弃。

## 8. `连接器BOM映射` 的治理

### 8.1 来源范围

`连接器BOM映射` 来自 `连接器物料选用清单.xlsx` 的 `连接器BOM对应关系` sheet。

当前治理后共有 6 条映射记录。

### 8.2 目标字段

| 字段 | 含义 |
| --- | --- |
| `知识类型` | 固定标识为连接器 BOM 映射。 |
| `来源文件`、`来源工作表`、`来源行号` | 记录原始出处。 |
| `序号` | BOM 层级序号，例如 `2`、`2.1`、`2.2`。 |
| `供应商连接器型号` | 图纸或客户侧可能出现的连接器型号。 |
| `中航物料号` | 映射后的中航物料号。 |
| `名称` | 连接器或附件名称。 |

### 8.3 主要治理动作

该 sheet 的原始结构较简单，治理过程主要是增加追溯字段和知识类型字段。

该表在后续模板回填中有两个用途：

1. 将图纸 OCR 中识别到的供应商连接器型号映射为中航物料号。
2. 如果某个连接器存在子序号，例如 `2` 下存在 `2.1`、`2.2`、`2.3`，则把对应附件物料一并展开到 `连接器及其所用辅材` sheet。

## 10. 当前自动选型如何使用治理结果

当前自动流程从用户图纸 OCR 结果中抽取需求，然后读取治理后的五个核心 sheet 生成推荐物料。大致逻辑如下：

1. 连接器匹配  
   OCR 中出现供应商连接器型号时，在 `连接器BOM映射` 中查找 `供应商连接器型号`，回填时使用 `中航物料号`。如果该连接器有子序号附件，则按 BOM 层级展开附件。

2. 导线匹配  
   OCR 中出现类似 `3mm²屏蔽线缆` 的需求时，先在 `导线标准线径` 中确认对应标准线径和外径，再到 `导线电缆知识` 中匹配物料规格、屏蔽要求、外径和优选等级。排序时优先级为一类高于二类，二类高于三类。

3. 防护辅材匹配  
   OCR 中如果指定波纹管、保护网、套管等防护辅材，会结合导线外径或线束外径估算值，在 `防护辅材知识` 中筛选内径、外径、颜色、材料和优选等级满足要求的物料。

4. 扎带卡扣匹配  
   OCR 中如果出现扎带、卡扣、管夹等材料需求，会在 `扎带卡扣知识` 中按照名称、规格、适配外径、适配孔径/螺栓/钣金厚度等字段匹配候选物料。

5. 模板回填  
   推荐结果最终写入接线表模板的新文件中，只使用模板格式，不保留模板原有示例内容。模板行数不足时，按模板行格式向后扩展。

## 11. 需要注意的限制

1. `导线标准线径` 不能按普通 sheet 简单读取  
   它是混合结构，包含标准段落、OCR 来源说明和多种表格形态。后续脚本必须使用专门解析器，否则容易丢失列或误把说明行当作数据行。

2. 优选等级需要保留依据  
   自动排序依赖优选等级。如果原始手册的等级信息来自颜色、分区或人工标注，应在 `等级依据` 或 `治理备注` 中保留说明。

3. 图片信息主要用于复核  
   扎带、卡扣等物料的图片可以帮助人工确认形态，但自动选型主要依赖结构化文本字段。

4. 原始手册更新后需要复核字段映射  
   如果后续手册新增 sheet、改表头、改合并单元格结构，治理脚本或解析规则需要同步检查，避免字段错位。

5. 找不到映射时不应强行补值  
   如果图纸中出现材料名称，但治理表中没有对应物料号，模板中应保留该材料需求，同时把物料号等无法确认字段留空，避免产生错误物料号。
